# Attendee instructions

This instructor-led and self-paced lab builds the Caldova Supplier Assurance Agent in Microsoft Copilot Studio.

## Start the lab

Review the [lab overview](../lab/README.md), then complete each section in order:

1. [Introduction and sign in](../lab/instructions/00-Introduction.md)
2. [Build the Supplier Assurance Agent](../lab/instructions/01-Build-The-Agent.md)
3. [Add skills and review an invoice](../lab/instructions/02-Add-Skills-And-Review-Invoice.md)
4. [Personalize, evaluate, and publish the agent](../lab/instructions/03-Evaluate-And-Publish.md)
5. [Build and test the workflow](../lab/instructions/04-Create-The-Workflow.md)
6. [Publish and test in Microsoft 365 Copilot](../lab/instructions/05-Publish-To-Microsoft-365-Copilot.md) (10-15 additional minutes)

For self-paced use, provision the prerequisites in the [environment guide](../environment/README.md) first. Skillable variables shown in the instructions must be replaced with values from your own environment.

## Optional bonuses

1. [Build the Supplier Assurance Dashboard](../lab/instructions/06-Bonus-Build-The-Supplier-Dashboard.md) (15-20 additional minutes).
2. [Create a Supplier Meeting Prep Agent with Copilot Cowork](../lab/instructions/07-Bonus-Create-An-Agent-With-Cowork.md) (15-20 additional minutes; requires the Frontier Copilot Studio skill).

Both bonuses follow the required publishing lab and can be skipped independently.
